# Wyrdtafl — product page

The public web page for **Wyrdtafl — The Judgement of the Norns**, a Norse tile game for Android by Skimiforow, and the host of its privacy policy.

The game's source lives in a private repository; this repository holds only the static site served by GitHub Pages:

- `index.html` — product page (features, screenshots, store link)
- `privacy/` — privacy policy in English, `privacy/pt/` in Portuguese
- `credits/` — credits
- `assets/` — icon, feature graphic, screenshots, the Cinzel typeface (SIL Open Font License, see `assets/OFL-Cinzel.txt`)

No build step: edit the HTML and push. `.nojekyll` keeps GitHub Pages from processing the files.
